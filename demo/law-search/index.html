🌐 如何让别人访问我的网站？（小白部署教程）

      

        

          
方式一：本机使用（零部署）

          
直接双击 index.html 用 Chrome / Edge 打开即可，无需任何服务器。

        

        

          
方式二：部署到互联网

          
网站是纯静态页面，把整个 legal-website 文件夹上传到静态托管（腾讯云 CloudBase / EdgeOne Pages 等）即可获得一个公网网址。详细图文步骤见项目根目录的 《使用说明.md》。

        

      

      
⚠️ 常见问题：双击打开后功能异常 → 换 Chrome/Edge 浏览器；导入数据不生效 → 某些浏览器限制本地文件存储，改用「本地服务器」方式（见使用说明）。

    

    

      
🔒 数据隐私说明

      
条文收藏、历史记录与自定义条文保存在你自己的浏览器本地（localStorage）；文献阅读模块的全部资料（PDF/DOCX/正文、摘录、思考、主题）保存在浏览器 IndexedDB 中，解析过程在本机完成，不上传任何服务器。网页 URL 导入仅在部署了配套服务端（server.js）时由你自己的服务器代为抓取。更换浏览器或电脑后数据不会同步，请定期使用「文献阅读 → 备份数据」导出 JSON 备份。
